# Infrastructure as Code (IaC) Projects

This repository contains sample Infrastructure as Code (IaC) projects using **Terraform** to provision cloud resources on **Azure**. The goal is to automate infrastructure setup and demonstrate best practices in cloud provisioning.

## 🔹 About
IaC allows you to manage and provision cloud infrastructure using code instead of manual processes. This repository includes examples ranging from simple VM deployments to multi-tier architectures.
